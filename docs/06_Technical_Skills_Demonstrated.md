## Key Technical Accomplishments
- Refactored Tempo-Bot from **Discord.js v12 → v14** and upgraded associated Node.js environments.  
- Maintained an isolated **testing environment** for safe deployment of new features.  
- Designed a **multi-layered access control model** integrating bot, role, and category permissions.  
- Wrote and deployed **regex-based filters** to prevent link spam, mention floods, and global ping abuse.  
- Configured automated alert routing to moderator-only channels for live event response.  
- Deployed system monitoring dashboards to visualize resource usage and uptime across multiple containers.
